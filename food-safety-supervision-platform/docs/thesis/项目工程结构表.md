# 项目工程结构表

本文档用于替代“项目工程结构图”，以表格形式展示 `food-safety-supervision-platform` 项目的主要工程结构，内容依据当前项目实际目录整理。

表5-3 项目工程结构表

| 层级 | 名称 | 类型 | 主要内容 | 说明 |
| --- | --- | --- | --- | --- |
| 根目录 | `food-safety-supervision-platform` | 项目根目录 | 聚合前端工程、后端微服务工程与公共模块 | 本项目总体工程目录 |
| 根目录 | `pom.xml` | 父工程配置 | Maven 聚合构建、统一依赖版本管理 | 后端多模块父工程 |
| 一级目录 | `food-web` | 前端工程 | `src/router`、`src/api`、`src/views/*` | 基于 Vue 3 的前端单页应用 |
| 二级目录 | `food-web/src/router` | 前端路由目录 | 角色路由、页面访问控制 | 管理页面导航与权限入口 |
| 二级目录 | `food-web/src/api` | 前端接口目录 | 网关接口封装 | 统一前后端请求调用 |
| 二级目录 | `food-web/src/views/public` | 前端页面目录 | 公众端页面 | 面向公告、公示、投诉等公开功能 |
| 二级目录 | `food-web/src/views/enterprise` | 前端页面目录 | 企业端页面 | 面向备案、产品档案、整改等功能 |
| 二级目录 | `food-web/src/views/systemAdmin` | 前端页面目录 | 系统管理员页面 | 面向监管账号管理 |
| 二级目录 | `food-web/src/views/regulatorAdmin` | 前端页面目录 | 区域管理员页面 | 面向审核、任务管理、统计等功能 |
| 二级目录 | `food-web/src/views/regulatorEnforcer` | 前端页面目录 | 执法人员页面 | 面向检查、抽检、投诉处理等功能 |
| 一级目录 | `gateway-service` | 后端微服务 | `src/main/java`、`src/main/resources` | 系统统一入口，负责路由转发与鉴权 |
| 一级目录 | `user-service` | 后端微服务 | `src/main/java`、`src/main/resources/sql` | 负责注册、登录、令牌校验与角色绑定 |
| 一级目录 | `regulation-service` | 后端微服务 | `src/main/java`、`src/main/resources/sql` | 负责企业备案、产品、监管人员、公告、文件、预警代理 |
| 一级目录 | `regulation-operation-service` | 后端微服务 | `src/main/java`、`src/main/resources/sql` | 负责检查、抽检、整改及预警 outbox 事件 |
| 一级目录 | `complaint-service` | 后端微服务 | `src/main/java`、`src/main/resources/sql` | 负责投诉提交、流转与处理 |
| 一级目录 | `warning-service` | 后端微服务 | `src/main/java`、`src/main/resources/sql` | 负责预警记录、处理日志与预警统计 |
| 一级目录 | `query-service` | 后端微服务 | `src/main/java`、`src/main/resources/sql` | 负责监管概览与预警统计聚合查询 |
| 一级目录 | `platform-common` | 公共模块 | `src/main/java` | 提供统一返回体与公共组件支持 |
| 二级目录 | `gateway-service/src/main/java` | 代码目录 | 网关过滤器、启动类等 | 体现统一接入层实现 |
| 二级目录 | `gateway-service/src/main/resources` | 配置目录 | 网关配置文件 | 包含路由与运行配置 |
| 二级目录 | `user-service/src/main/java` | 代码目录 | 控制器、服务、实体、工具类 | 体现认证与用户管理实现 |
| 二级目录 | `user-service/src/main/resources/sql` | 数据脚本目录 | 建表脚本 | 用户与角色相关表结构 |
| 二级目录 | `regulation-service/src/main/java` | 代码目录 | 企业、产品、监管人员、公告、文件、预警代理相关代码 | 体现监管主数据能力 |
| 二级目录 | `regulation-service/src/main/resources/sql` | 数据脚本目录 | 建表脚本 | 企业、产品、公告、监管人员等表结构 |
| 二级目录 | `regulation-operation-service/src/main/java` | 代码目录 | 检查、抽检、整改、outbox 相关代码 | 体现监管执行过程实现 |
| 二级目录 | `regulation-operation-service/src/main/resources/sql` | 数据脚本目录 | 建表脚本 | 检查、抽检、整改等表结构 |
| 二级目录 | `complaint-service/src/main/java` | 代码目录 | 投诉命令、查询、流转处理相关代码 | 体现投诉处理链路 |
| 二级目录 | `complaint-service/src/main/resources/sql` | 数据脚本目录 | 建表脚本 | 投诉与处理记录表结构 |
| 二级目录 | `warning-service/src/main/java` | 代码目录 | 预警记录、内部事件接口、处理接口、统计代码 | 体现预警中心实现 |
| 二级目录 | `warning-service/src/main/resources/sql` | 数据脚本目录 | 建表脚本 | 预警记录与处理日志表结构 |
| 二级目录 | `query-service/src/main/java` | 代码目录 | 概览统计、预警统计聚合相关代码 | 体现跨服务查询聚合能力 |
| 二级目录 | `query-service/src/main/resources/sql` | 数据脚本目录 | 建表脚本 | 查询扩展表结构 |
| 二级目录 | `platform-common/src/main/java` | 代码目录 | 公共返回体、通用组件 | 供各微服务复用 |
