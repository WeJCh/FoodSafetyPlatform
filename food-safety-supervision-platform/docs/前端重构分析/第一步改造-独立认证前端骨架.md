# 第一步改造：独立认证前端骨架

更新时间：2026-04-10

## 1. 本次目标

基于前期扫描结果，新建一个独立前端项目骨架，不修改 `food-web`，并优先实现以下第一批认证页面：

- 登录页
- 公众注册页
- 企业注册页骨架
- 忘记密码页

本次明确不处理：

- 登录成功过渡页
- 任何认证后的业务页面

## 2. 新项目目录

本次新增独立前端目录：

- `food-auth-web/`

该目录与现有 `food-web/` 平行存在，避免影响当前旧前端。

## 4. 新增/修改的路由

本次新增的正式路由如下：

- `/`：重定向到 `/login`
- `/login`：登录页
- `/register/public`：公众注册页
- `/register/enterprise`：企业注册页
- `/forgot-password`：忘记密码页
- `/:pathMatch(.*)*`：兜底重定向到 `/login`

说明：

- 当前项目已改为 `vue-router` 结构
- 不再使用旧前端 `App.vue` 里通过 `view` 字段切换页面的方式

## 5. 页面之间如何跳转

### 5.1 登录 -> 注册

在登录页 `LoginView.vue` 中：

- 点击“公众注册”卡片，跳转到 `/register/public`
- 点击“企业入驻”卡片，跳转到 `/register/enterprise`

### 5.2 注册 -> 登录

在公众注册页 `PublicRegisterView.vue` 中：

- 顶部主按钮区提供“返回登录”
- 页面底部提供“立即登录”
- 两者都跳转到 `/login`

在企业注册页 `EnterpriseRegisterView.vue` 中：

- 点击“返回登录”跳转到 `/login`

### 5.3 登录 -> 忘记密码

在登录页 `LoginView.vue` 中：

- 点击“忘记密码？”跳转到 `/forgot-password`

### 5.4 忘记密码 -> 登录

在忘记密码页 `ForgotPasswordView.vue` 中：

- 点击“返回登录”跳转到 `/login`

## 6. 本次实现说明

### 6.1 登录页

来源：

- 参考 Stitch 原型 `_1/code.html`

实现情况：

- 保留用户名、密码、记住我、忘记密码入口
- 保留“尚未拥有账户”的双入口结构
- 已接入“公众注册”
- 已接入“企业入驻”
- 登录接口复用现有后端地址：
  - `/api/auth/login`

### 6.2 公众注册页

来源：

- 参考 Stitch 原型 `_2/code.html`

实现情况：

- 实现字段：
  - `username`
  - `phone`
  - `password`
  - `agreed`
- 接口复用现有后端地址：
  - `/api/users/register/public`
- 采取最小字段适配策略，不额外引入旧前端里的 `realName`

### 6.3 企业注册页

来源：

- 参考 Stitch 原型 `_3/code.html`

实现情况：

- 保留原型中的核心分段结构：
  - 企业主体信息
  - 负责人信息
  - 账号与安全凭证
  - 证照材料占位
- 当前提交到接口的字段只有：
  - `username`
  - `password`
  - `realName`，由“主要负责人姓名”映射
  - `phone`
- 新增一个最小前端适配字段“登录账号”，用于对齐现有企业注册接口
- 企业名称、统一社会信用代码、企业类型、官方邮箱、营业执照文件当前只保留在前端骨架中，不提交到后端
- 企业注册接口复用现有后端地址：
  - `/api/users/register/enterprise`

### 6.4 忘记密码页

来源：

- 由登录页中的“忘记密码”入口补齐

实现情况：

- 当前只实现前端页面、表单占位和路由闭环
- 未调用后端接口
- 页面上已明确提示：当前仓库中未扫描到忘记密码接口
